## 1. 디자인 원칙

"계측기"를 고른 이상, 그게 실제로 무슨 뜻인지 규칙으로 못 박아둡니다. 아래 6개가 모든 판단의 기준입니다.

### 원칙 1 — 숫자가 주인공이다

이 사이트에서 사용자가 실제로 읽는 것은 `0:42`, `120g`, `94°C`, `24클릭` 넉 자리입니다. 나머지는 전부 그 숫자를 설명하는 부속입니다.

- 값은 크게, 라벨은 작고 흐리게. **크기 차이를 최소 2.5배**로 벌립니다
- 단위(g, °C, s, 클릭)는 값보다 한 단계 작게 붙입니다. 계측기 관례이고, 값의 시각적 무게를 지킵니다
- 숫자는 **반드시 tabular-nums**. 타이머가 `0:09 → 0:10`으로 넘어갈 때 글자가 흔들리면 계측기가 아닙니다

### 원칙 2 — 장식을 쓰지 않는다

- 그림자 없음. 입체감 없음. 그라데이션 없음
- 구분은 **1px 선**과 **여백** 두 가지로만
- 아이콘은 정보를 대체할 때만 씁니다. 예쁘게 하려고 넣지 않습니다
- 둥근 모서리는 최대 8px. 알약 모양은 칩(태그)에만

### 원칙 3 — 여백이 구분선이다

선을 긋기 전에 여백을 먼저 씁니다. 선은 여백으로 안 되는 곳에만 씁니다.

- 섹션 사이 32px, 그룹 사이 16px, 항목 사이 8px
- 이 규칙만 지키면 선이 거의 필요 없어집니다

### 원칙 4 — 색은 상태를 말할 때만 쓴다

포인트 색은 "지금 진행 중", "선택됨", "이걸 누르세요" 세 가지에만 씁니다. 그 외는 전부 무채색입니다.

- 색을 아껴야 포인트 색이 실제로 눈에 들어옵니다
- **색만으로 정보를 전달하지 않습니다.** 항상 텍스트나 위치가 함께 있어야 합니다

### 원칙 5 — 추출 화면은 안 봐도 되게 만든다

P4 가이드는 **손에 주전자를 들고 있는 상태**에서 씁니다. 이 전제가 모든 결정을 지배합니다.

- 팔 길이(약 50cm)에서 읽혀야 함 → 타이머 64px, 목표 물량 40px
- 진동과 소리로 다음 단계를 알림. 화면은 확인용
- 버튼은 화면 하단 1/3에만. 엄지가 닿는 곳
- 젖은 손 전제 → 터치 타깃 최소 44×44px, 실수로 나가지지 않게 이탈에 확인 단계

### 원칙 6 — 플레이버 휠 색과 싸우지 않는다

플레이버 휠은 9개 대분류에 각각 고유색이 필요합니다(빨강·주황·노랑·초록·갈색·보라·분홍…). 사이트 UI가 유채색을 많이 쓰면 휠이 죽습니다.

- 그래서 UI 기본을 무채색으로 잡았습니다
- 포인트 색은 **청록(teal)** 으로 정했습니다. 플레이버 휠 팔레트에 청록 계열이 없어 충돌하지 않습니다

## 3. 타이포그래피

### 3.1 폰트

```css
font-family: 'Pretendard Variable', Pretendard, -apple-system,
             'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, sans-serif;
font-feature-settings: 'tnum' 1;   /* 전역 tabular numerals */
```

Pretendard를 쓰는 이유: 한글·영문·숫자 굵기가 균일해 숫자 중심 UI에서 안정적이고, 가변 폰트라 굵기 단계를 자유롭게 씁니다. 미로딩 시 시스템 폰트로 폴백됩니다.

**`tnum`을 전역으로 켜는 것이 이 디자인의 핵심 설정입니다.** 이게 없으면 타이머와 무게 표시가 매 프레임 미세하게 흔들립니다.

### 3.2 스케일 (모바일 기준)

| 이름 | 크기 | 굵기 | 자간 | 행간 | 용도 |
|---|---|---|---|---|---|
| `display` | 64 | 600 | -0.03em | 1.0 | 타이머 |
| `metric` | 40 | 600 | -0.02em | 1.05 | 목표 물량, 점수 |
| `metric-sm` | 26 | 600 | -0.01em | 1.1 | 카드 내 수치 |
| `title` | 20 | 600 | -0.01em | 1.35 | 화면 제목 |
| `subtitle` | 16 | 600 | 0 | 1.4 | 섹션 제목 |
| `body` | 15 | 400 | 0 | 1.65 | 본문 |
| `label` | 13 | 500 | 0 | 1.4 | 입력 라벨, 버튼 |
| `caption` | 11 | 600 | 0.06em | 1.3 | 지표 라벨 (대문자) |

PC(≥768px)에서는 `display`만 88px로 키우고 나머지는 그대로 둡니다. 본문 크기를 키우면 정보 밀도가 떨어집니다.

### 3.3 숫자 표기 규칙

```
120 g       ← 값 40px / 단위 16px / 사이 4px
94 °C       ← 도(°) 기호는 단위에 붙임
0:42        ← 타이머는 콜론 포함 고정폭
24 클릭      ← 한글 단위도 동일 규칙
1:16        ← 비율은 콜론, 단위 없음
+2밴드      ← 부호를 반드시 표기 (상대값임을 명시)
```

## 4. 레이아웃

### 4.1 그리드

- 모바일: 단일 컬럼, 좌우 패딩 20px
- 태블릿(≥600px): 좌우 패딩 32px, 최대 폭 560px 중앙 정렬
- PC(≥1024px): 최대 폭 1120px, 2컬럼 허용 (목록+상세)

**PC에서도 최대 폭을 제한합니다.** 계측기는 정보가 한눈에 들어와야 하고, 화면 끝까지 늘어난 텍스트는 읽기 나쁩니다.

### 4.2 여백 스케일

4px 배수만 씁니다: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64`

| 상황 | 값 |
|---|---|
| 아이콘과 텍스트 사이 | 8 |
| 라벨과 값 사이 | 4 |
| 리스트 항목 사이 | 12 |
| 카드 내부 패딩 | 16~20 |
| 그룹 사이 | 24 |
| 섹션 사이 | 32 |
| 화면 상단 여백 | 24 |

### 4.3 하단 탭 바

```
높이 56px + env(safe-area-inset-bottom)
4개 탭: 추출 / 탐색 / 기록 / 위키
아이콘 22px + 라벨 11px
활성: --accent + 굵기 600
비활성: --ink-3 + 굵기 500
상단 1px --line
```

**추출 가이드 진행 중에는 탭 바를 숨깁니다.** 몰입 화면이고, 실수로 나가면 타이머가 날아갑니다.

## 5. 컴포넌트

### 5.1 MetricCard — 이 디자인의 기본 단위

```
┌──────────────────┐
│ 온도              │  caption 11px / --ink-3 / 대문자 자간
│                  │  ← 4px
│ 94 °C            │  metric-sm 26px / --ink
│                  │  ← 4px
│ 원본 96°C         │  caption / --ink-4 / 변환 시에만
└──────────────────┘
   패딩 16 / 테두리 1px --line / 반경 8
```

레시피 상세와 추천 결과에서 2×2 그리드로 배치합니다: 비율 · 온도 · 총 시간 · 분쇄.

### 5.2 Chip — 플레이버 태그, 필터

```
기본    배경 transparent / 테두리 1px --line-strong / --ink-2
선택됨  배경 --accent-weak / 테두리 1px --accent / --accent / 굵기 600
높이 34px / 좌우 패딩 14px / 반경 17px (알약)
```

플레이버 칩만 예외적으로 좌측에 6px 색 점을 붙입니다. 대분류 색을 표시하되, **색 점은 보조이고 텍스트가 항상 있습니다**(원칙 4).

### 5.3 ScoreBar — 추천 점수

```
87점  ← metric-sm, --ink
▓▓▓▓▓▓▓▓▓░  ← 높이 6px / 트랙 --accent-weak / 채움 --accent / 반경 3
```

점수 옆에 근거 3줄이 항상 따라붙습니다. 숫자만 보여주면 근거를 못 배웁니다.

```
✓ 라이트 + 워시드 완전 일치     ← --accent
✓ 목표 '클래리티'와 일치        ← --accent
△ Solo Dripper → V60 변환 필요  ← --warn
```

체크(✓)와 주의(△) 기호를 쓰는 이유: 색맹 사용자도 구분 가능해야 합니다.

### 5.4 StepTimeline — 레시피 단계 (모바일 세로)

```
 0:00  ┃ 블룸           45 g
       ┃ 10초 · 나선
       ┃
 0:45  ┃ 2차 푸어       145 g
       ┃ 20초 · 나선
       ┃
 1:30  ┃ 3차 푸어       240 g
       ┃ 25초 · 중앙
       ╹
 3:10  ● 드리퍼 제거
```

- 세로선은 2px `--line-strong`, 진행된 구간은 `--accent`
- 시각은 좌측 고정폭(52px)으로 정렬. tabular-nums로 자릿수 흔들림 방지
- 물량은 우측 정렬. **누적값**임을 헤더에 명시

### 5.5 대형 액션 버튼

```
높이 52px / 반경 8 / 폭 100%
주요: 배경 --accent / 글자 --paper / 굵기 600 / 15px
보조: 배경 transparent / 테두리 1px --line-strong / 글자 --ink
비활성: 배경 --line / 글자 --ink-4
```

화면당 주요 버튼은 **하나만** 둡니다. 두 개면 사용자가 멈칫합니다.

### 5.6 아코디언 (추천 입력)

```
접힘:  ▸ 내 장비    V60 02 플라스틱 · Timemore C3    [변경]
       ← 요약값을 --ink-2로 항상 보여줌. 열지 않아도 확인 가능

펼침:  ▾ 원두
       (내용)
```

기본은 `내 장비` 접힘 + `원두` 펼침 + `목표` 접힘. **탭 4번 안에 추천 결과에 도달**하는 것이 목표입니다.

## 6. 화면별 디자인 결정

### 6.1 P4 추출 가이드 — 가장 중요한 화면

```
┌───────────────────────────┐
│ ✕ 나가기          🔒 화면유지│  44px, --ink-3
├───────────────────────────┤
│ 지난 메모                   │  caption / --ink-3
│ 온도 88°C, 마지막 -20g      │  body / --ink-2 / --surface 배경
├───────────────────────────┤
│                           │
│         0:42              │  display 64 / --ink
│                           │
│   ▓▓▓▓▓▓▓░░░░  3/5        │  6px 바 + caption
│                           │
│   ─────────────────       │  1px --line
│                           │
│      2차 푸어              │  subtitle / --accent
│                           │
│       120 g               │  metric 40 / --ink
│                           │
│   20초 동안 · 스파이럴       │  body / --ink-3
│                           │
│   다음까지 8초              │  caption / --ink-3
│                           │
├───────────────────────────┤
│  ⏸ 일시정지  │   다음 ▶    │  52px, 하단 고정
└───────────────────────────┘
```

**세부 결정**

| 항목 | 결정 | 이유 |
|---|---|---|
| 화면 회전 | 세로 고정 | 가로로 들 상황이 없음 |
| 화면 꺼짐 | Wake Lock API | 추출 3분 동안 꺼지면 안 됨 |
| 3초 전 알림 | 진동 + 소리 + 숫자 색 변화 | 3중으로 알려야 놓치지 않음 |
| 나가기 | 확인 다이얼로그 | 오조작로 타이머 유실 방지 |
| 탭 바 | 숨김 | 몰입 + 오조작 방지 |
| 다음 버튼 | 항상 활성 | 사람은 목표 무게 채우느라 늦음. 실제 누른 시각을 기록 |
| 배경 | 순수 `--paper` | 어떤 장식도 숫자와 경쟁하면 안 됨 |

**단계 전환 애니메이션**: 150ms 페이드만. 슬라이드나 바운스는 쓰지 않습니다. 추출 중에 시선을 뺏으면 안 됩니다.

### 6.2 P2 플레이버 탐색 — 색을 쓰는 유일한 화면

- 대분류 9개는 각자 고유색을 가집니다. 여기서만 유채색이 허용됩니다
- 나머지 UI(칩, 버튼, 카운터)는 전부 무채색으로 눌러둡니다
- **자체 팔레트를 정의합니다** — SCA 공식 팔레트를 그대로 쓰지 않습니다(CC BY-NC-ND의 ND 조항)

| 대분류 | 색 | 비고 |
|---|---|---|
| Fruity | `#C0392B` | |
| Sour / Fermented | `#D4A017` | |
| Green / Vegetative | `#4B8B3B` | |
| Other | `#7F8C8D` | |
| Roasted | `#8B4513` | |
| Spices | `#B7472A` | Fruity와 명도 차이로 구분 |
| Nutty / Cocoa | `#A0714F` | |
| Sweet | `#E0A458` | |
| Floral | `#B565A7` | |

색맹 대응: 인접 섹터끼리 명도 차이를 최소 15% 두고, **모든 섹터에 텍스트 라벨을 함께 표시**합니다.

### 6.3 P5 로그 — 비교가 목적

목록에서 가장 중요한 정보는 "지난번과 뭐가 달랐나"입니다.

```
8/14  에티오피아 구지          7.5
      V60 · 89°C · 24클릭
      ↑ 온도 -1  ↓ 분쇄 +2     ← 이전 로그 대비 diff, --accent
```

diff 표기가 목록 단계에서 보이면 스크롤만으로 다이얼인 과정이 읽힙니다.

## 7. 모션

계측기에는 과한 모션이 없습니다. 아래 4개만 씁니다.

| 상황 | 지속 | 이징 |
|---|---|---|
| 화면 전환 | 200ms | `cubic-bezier(.2,0,0,1)` |
| 아코디언 펼침 | 180ms | `ease-out` |
| 진행 바 | 300ms | `linear` (시간 기반이므로 등속) |
| 칩 선택 | 120ms | `ease-out` |

`prefers-reduced-motion: reduce`이면 전부 0ms로 만듭니다.

**진행 바에 `linear`를 쓰는 이유**: 시간을 나타내는 바가 가속·감속하면 계측값을 거짓말하는 셈이 됩니다.

## 8. 다국어가 디자인에 미치는 영향

한/영을 지원하기로 하면서 레이아웃 규칙 몇 개가 강제됩니다. 나중에 고치면 전면 수정이 되니 지금 못 박습니다.

### 8.1 영어는 한국어보다 길다

같은 뜻을 영어로 쓰면 평균 **1.3~1.6배** 길어집니다. 버튼 폭을 한국어 기준으로 잡으면 영어판에서 전부 터집니다.

| 한국어 | 영어 | 배율 |
|---|---|---|
| 다음 (2자) | Next (4자) | 2.0× |
| 일시정지 (4자) | Pause (5자) | 1.3× |
| 화면 유지 (4자) | Keep screen on (14자) | 3.5× |
| 이 레시피로 시작 (8자) | Start this recipe (17자) | 2.1× |
| 내 장비 기준 변환값 (9자) | Converted for your setup (24자) | 2.7× |

**규칙**
- 버튼과 라벨에 **고정 `width`를 쓰지 않습니다.** `padding` 기반으로만 폭을 만듭니다
- 가로 나열 요소는 `flex-wrap: wrap` 허용. 2줄이 되는 걸 막지 않습니다
- `caption`(11px) 라벨은 영어에서 2줄이 되기 쉬우므로 컨테이너에 `min-height`를 주지 않습니다
- **텍스트 잘림(ellipsis)은 최후 수단**입니다. 계측기에서 "Conver…"는 정보 손실입니다

### 8.2 줄바꿈 규칙이 언어마다 다르다

한국어는 어절 중간에서 끊기면 읽기 나쁩니다. 영어는 기본 동작이 맞습니다.

```css
:lang(ko) { word-break: keep-all; overflow-wrap: break-word; }
:lang(en) { word-break: normal;   overflow-wrap: break-word; }
```

`word-break: keep-all`을 전역으로 걸면 영어 긴 단어가 컨테이너를 뚫습니다. **반드시 `:lang()`으로 분리합니다.** `<html lang>`을 언어 전환 시 함께 바꿔야 이게 작동합니다.

### 8.3 자간

| 언어 | display / metric | body |
|---|---|---|
| 한국어 | `-0.01em` | `0` |
| 영어 | `-0.02em` | `0` |

영어는 큰 크기에서 자간을 더 조여야 뭉쳐 보입니다. 한글에 같은 값을 주면 글자가 붙어 읽기 나빠집니다.

```css
:lang(en) .display, :lang(en) .metric { letter-spacing: -0.02em; }
```

### 8.4 폰트는 그대로 간다

Pretendard는 Inter 기반이라 라틴 문자 품질이 좋습니다. **영어판에 별도 폰트를 붙이지 않습니다.**

- 두 언어가 같은 폰트를 쓰면 숫자 모양이 일치해 계측기 톤이 유지됩니다
- 언어별로 폰트를 바꾸면 `tnum` 설정과 숫자 폭이 달라져 타이머 레이아웃이 흔들립니다

### 8.5 날짜·단위 표기

| 항목 | ko | en | 비고 |
|---|---|---|---|
| 날짜 (목록) | `8/14` | `Aug 14` | 영어는 폭이 넓음 → 날짜 컬럼 36px → 52px |
| 온도 | `94 °C` | `94 °C` | 언어와 무관. °F는 별도 설정 |
| 분쇄 | `24 클릭` | `24 clicks` | 복수형 처리 필요 (`1 click` / `2 clicks`) |
| 단계 | `3 / 5 단계` | `Step 3 / 5` | 어순이 다름 → 통문장 키로 관리 |

로그 목록의 날짜 컬럼은 **영어 기준(52px)으로 잡습니다.** 한국어에서 여백이 남는 편이, 영어에서 줄바꿈되는 것보다 낫습니다.

### 8.6 언어 전환 UI

```
위치   설정 화면 + 위키 탭 상단 (본문이 긴 곳)
형태   [ 한국어 | EN ]  세그먼트 토글
크기   높이 32px, 각 항목 최소 44px 터치 영역
```

국기 아이콘을 쓰지 않습니다. 언어와 국가는 다르고, 영어는 특정 국가의 것이 아닙니다.

### 8.7 폴백 배지

번역이 없는 해설에 붙는 표시입니다. 눈에 띄되 방해하지 않아야 합니다.

```
┌────────────────────────────────┐
│ ⓘ Korean only                  │  caption 11px / --ink-3
│                                │  배경 --surface / 좌측 2px --line-strong
│ (한국어 원문)                    │  body / --ink-2
└────────────────────────────────┘
```

`--warn` 색을 쓰지 않습니다. 오류가 아니라 상태이고, 경고색을 남발하면 진짜 경고가 묻힙니다.
